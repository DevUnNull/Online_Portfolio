About SSS StudioVề SSS Studio

SSS (Super Startup Simulator) is an independent game studio from Vietnam, founded by UnNull (Nguyễn Mai Ngọc Hải). We make indie games such as 707: The Reunion and Brainrot Runner, and build games for partners as an outsourcing studio. SSS (Super Startup Simulator) là studio game độc lập tại Việt Nam, sáng lập bởi UnNull (Nguyễn Mai Ngọc Hải). Chúng tôi làm các tựa game indie như 707: The Reunion, Brainrot Runner và nhận gia công phát triển game cho đối tác.

Core ObjectiveMục tiêu cốt lõi

Build and release high-quality games & applications, focusing on realistic physics interactions and creating great entertainment value for players. Xây dựng và phát hành các tựa game & ứng dụng chất lượng cao, tập trung vào trải nghiệm tương tác vật lý chân thực và tạo ra giá trị giải trí lớn cho người chơi.

Development PhilosophyTriết lý phát triển

Put player experience at the center. Harmoniously combine engaging gameplay, smooth physics mechanics, and maximum performance optimization across all devices. Đặt trải nghiệm người chơi làm trung tâm. Kết hợp hài hòa giữa gameplay lôi cuốn, cơ chế vật lý mượt mà và tối ưu hóa hiệu năng tối đa trên mọi thiết bị.

ENGINE · LEGENDARY

Unity Engine & C#

Program core logic optimizing MonoBehaviour structure, computing Rigidbody physics systems, and smooth Animation states. Lập trình logic cốt lõi ứng dụng cấu trúc MonoBehaviour tối ưu, tính toán hệ thống vật lý Rigidbody và hệ quản lý Animation mượt mà.

ARCHITECTURE · EPIC

Clean Architecture

Design clean, layered codebase structure, applying Design Patterns (Factory, Observer, Singleton) to decouple complex systems. Thiết kế mã nguồn tách biệt phân lớp rõ ràng, áp dụng Design Patterns (Factory, Observer, Singleton) giải quyết triệt để bài toán phình to dữ liệu game.

OPERATIONS · RARE

DevOps & Data

Manage codebases with advanced Git, automated asset packaging, and state synchronization persistence with SQLite. Quản trị mã nguồn bằng Git nâng cao, đóng gói tài nguyên tự động, cùng hệ thống lưu trữ đồng bộ trạng thái qua SQLite.

PACKAGES · EPIC

Unity Packages

Develop and package reusable modular utilities (Upgrade System, Object Pooling, Save System) to expedite development cycles. Xây dựng và đóng gói các thư viện modular tái sử dụng như Upgrade System, Object Pooling, Save System giúp tối ưu hóa thời gian phát triển game.
